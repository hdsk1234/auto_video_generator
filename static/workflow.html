핵심 5단계 비디오 생성 파이프라인

인풋(Input) • 툴(Tool) • 아웃풋(Output) 프로세스 요약

스튜디오 열기
STEP 1 script.txt

대본 작성 & 씬 분할

인풋 (Input)

사용자 원고 텍스트

툴 (Tool)

Web UI 에디터 & 텍스트 청킹 파서

아웃풋 (Output)

script.txt (씬 분할 텍스트)

STEP 2 Audio + SRT

음성·자막 생성

인풋 (Input)

Step 1 분할 대본 (script.txt)

툴 (Tool)

ElevenLabs API (TTS 타임스탬프) & 오디오 무음 제거

아웃풋 (Output)

tts_audio.mp3, subtitles.srt

STEP 3 images/*.png

자막 기반 Gemini 이미지 생성

인풋 (Input)

Step 2 생성 자막 (subtitles.srt)

툴 (Tool)

Google Gemini Imagen 3 API (씬별 9:16 비주얼 렌더링)

아웃풋 (Output)

images/scene_*.png (고화질 이미지)

STEP 4 flow_videos/

이미지 기반 Flow 영상 생성

인풋 (Input)

Step 3 이미지 (scene_*.png) + 모션 프롬프트

툴 (Tool)

Google Labs Flow AI (Image-to-Video) 자동화 / 업로드

아웃풋 (Output)

flow_videos/*.mp4 (씬별 영상 클립)

STEP 5 final_video.mp4

최종 MP4 합성 렌더링

인풋 (Input)

flow_videos/*.mp4 (또는 images) + tts_audio + srt

툴 (Tool)

FFmpeg (H.264 인코더, libass 자막 번인, 오디오 싱크)

아웃풋 (Output)

final_video.mp4 (1080p 완성본)

1 대본 입력
2 음성·자막 생성
3 Gemini 이미지 생성
4 Flow 영상 생성
5 최종 MP4 완성
