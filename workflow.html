핵심 4단계 비디오 생성 파이프라인

인풋(Input) • 툴(Tool) • 아웃풋(Output) 프로세스 요약

스튜디오 열기
STEP 1 script.txt

대본 작성 & 씬 분할

인풋 (Input)

사용자 원고 텍스트

툴 (Tool)

Web UI 에디터 & 텍스트 청킹 파서

아웃풋 (Output)

script.txt (씬 분할 텍스트)

STEP 2 Audio + Prompts

음성·자막 & 프롬프트

인풋 (Input)

Step 1 분할 대본 (script.txt)

툴 (Tool)

ElevenLabs API (TTS·타임스탬프) + OpenAI GPT-4o API

아웃풋 (Output)

tts_audio.mp3, subtitles.srt, prompts.json

STEP 3 flow_videos/

Google Flow 영상 생성

인풋 (Input)

Step 2 시각 프롬프트 (prompts.json)

툴 (Tool)

Google Labs Flow AI + Playwright 브라우저 자동화 (또는 수동 업로드)

아웃풋 (Output)

flow_videos/*.mp4 (씬별 영상 클립)

STEP 4 final_video.mp4

최종 MP4 합성 렌더링

인풋 (Input)

flow_videos/*.mp4 + tts_audio.mp3 + subtitles.srt

툴 (Tool)

FFmpeg (H.264 인코더, libass 자막 번인, 오디오 믹싱)

아웃풋 (Output)

final_video.mp4 (1080p 완성본)

1 대본 입력
2 음성·자막 & 프롬프트
3 Flow 영상 생성
4 최종 MP4 완성
